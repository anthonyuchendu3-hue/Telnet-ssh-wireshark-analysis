# Screenshots

Place your **redacted** screenshots here using these names:

| File | What to capture |
|------|-----------------|
| `telnet-filter.png` | Wireshark with the `telnet` display filter applied |
| `telnet-stream.png` | Follow → TCP Stream window for the Telnet session |
| `ssh-filter.png` | Wireshark with the `ssh` display filter applied |
| `ssh-stream.png` | Follow → TCP Stream window for the SSH session |

## Redaction checklist (before you commit)

- [ ] Usernames blurred or blocked out
- [ ] Passwords blurred or blocked out
- [ ] Hostnames and private IP addresses removed
- [ ] No tokens, keys or other secrets visible
- [ ] Browser tabs, desktop notifications and other windows cropped out

Keep unredacted originals in `screenshots/raw/` (git-ignored) or outside the repo entirely.
